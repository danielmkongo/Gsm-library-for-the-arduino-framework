# Gsm-library-for-the-arduino-framework

> An Arduino-framework C++ library by Daniel Mkongo for driving GSM modules (SIM800 family, A6, A7) over AT commands: SMS and HTTP downloads without hand-writing AT parsing.

This library simplifies the interaction between your microcontroller and GSM. 

supports:

-A6 GSM
-A7 GSM
-SIM800L
-SIM800C
-SIM800
etc.
